# Security policy

## Beta warning

The current beta sends files and transfer codes over unencrypted HTTP. Do not use it for sensitive files or on untrusted networks. The receive server should only be enabled on a trusted local Wi-Fi network and must not be exposed to the internet.

## Reporting a vulnerability

Please report security issues privately using the repository's GitHub Security Advisories feature. Include affected versions and steps to reproduce. Do not publish sensitive details before a fix is available.
